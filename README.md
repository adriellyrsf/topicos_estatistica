# Análise dos Fatores Associados ao Burnout em Trabalhadores no Regime de Trabalho Remoto

[Acesse o Relatório Completo Aqui](https://adriellyrsf.github.io/topicos_estatistica/)

---

### Sobre o Projeto
Análise dos fatores associados ao escore de burnout em trabalhadores remotos a partir de dados simulados. O estudo abrangeu análises descritivas, de correlação e o ajuste de um modelo de regressão linear múltipla (R² ≈ 0,92), destacando a taxa de conclusão de tarefas/produtividade como o principal fator associado ao desfecho.
